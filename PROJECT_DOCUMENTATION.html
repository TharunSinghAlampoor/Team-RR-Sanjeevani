1. System Overview

The Sanjeevani Healthcare E-Commerce Platform is an enterprise medical equipment, healthcare supplies, and pharmaceutical e-commerce web application. It features a high-performance RESTful API backend built on Spring Boot 3 and Spring Security 6 with JWT authentication, coupled to a React 18 frontend powered by Vite, Razorpay Payment Gateway, and GPS Location Auto-Detection.

2. Core Modules & Specifications

  • Stateless Security & JWT Auth: Spring Security 6 filter chain with BCrypt password encoding, JWT Bearer token verification, and non-blocking guest request handling.
  • Catalog & Product Engine: REST APIs for dynamic categories, product search, filtering, and instant product details overlays.
  • GPS Location Auto-Detection: Integrates browser Geolocation API and OpenStreetMap Nominatim reverse geocoding to automatically detect delivery address.
  • Razorpay Payment Gateway: Complete 3-step payment flow: Order Initialization, Client Checkout Modal, and Server Signature Verification (HMAC SHA-256).
  • Order Management & Reverse Chronological Sorting: Real-time order placement, tracking stepper, and order history sorted from Latest to Oldest.
  • Downloadable Printable Invoice: Ultra-clean, human-readable invoice format with Sanjeevani company branding, itemized tables, and toll-free helpline 18001234321.

3. Spring Security 6 Configuration

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .cors(cors -> cors.configurationSource(corsConfigurationSource()))
            .csrf(csrf -> csrf.disable())
            .sessionManagement(sm -> sm.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(
                    "/api/auth/**",
                    "/categories", "/categories/**",
                    "/products", "/products/**",
                    "/api/categories/**", "/api/products/**"
                ).permitAll()
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }
}

4. Key API Endpoints

HTTP Method Endpoint Path Access Level Description
POST /api/auth/register Public Register new user account
POST /api/auth/login Public Authenticate user & return JWT token
GET /categories Public Fetch all product categories
GET /products Public Fetch product catalog with search & category filters
POST /api/payments/razorpay-order Authenticated Create Razorpay Order ID
POST /api/payments/verify Authenticated Verify Razorpay HMAC SHA-256 signature
GET /api/orders Authenticated Retrieve user order history (Latest to Oldest)
